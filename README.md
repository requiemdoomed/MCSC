# Manaslu Computer Science Club

A responsive website for a computer science community in
Butwal, Nepal.

## Features

- Club introduction and team profiles
- Programming and technology interests
- GYRO-76 robotics concept showcase
- Expandable project details and animations
- Mobile-friendly layout and email contact

## Built With

HTML, CSS, and JavaScript.

## Run

Download the project and open `MCSC(1).html` in your browser.
No installation required.
